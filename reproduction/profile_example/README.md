# Profile example

Run `python3 -I -B analysis/bandha_profile_example.py --out reproduction/profile_example/results` from the repository root. This standard-library analytic check derives the paper example from fixed labels and flags, verifies its coefficient identity and direct-versus-profile reconstruction in 81 rational parameter cases, and generates the manuscript value macros.

These are exact constructed outcomes, not new RAGTruth measurements or correction-system runs.
