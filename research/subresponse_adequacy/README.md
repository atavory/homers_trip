# Declared-Use Evaluation Adequacy

The CSV records thirteen action/loss cases and information requirements.
These are derived adequacy statements under declared assumptions, not
thirteen measured failures of published models. Status and qualifications
must be retained when interpreting each row.

The paper uses selected highlighting, editing, generation and matching cases.
The full map additionally includes separate fixed-budget and complete-support
uses; neither defines the paper's main adaptive-review objective.

Published FRED values can be transcribed from the primary HTML using
analysis/bandha_published_case_values.py with --fred-html, --adequacy-csv
and --out. Obtain the v2 HTML at https://arxiv.org/html/2507.20930v2.
The script checks the FAVA table captions and named columns, records the
source hash, and emits CSV, JSON and TeX.
